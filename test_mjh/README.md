# 候选集测试

在仓库根目录运行 `python -m test_mjh.server`，然后打开 `http://127.0.0.1:8766/`。页面和接口由独立测试服务提供，SQLite 规则库通过只读连接访问。

运行 `python -m unittest discover -s test_mjh` 可以验证筛选逻辑。

## CP-SAT 路线优化

使用 Python 3.10 或更高版本运行 `python -m pip install -r test_mjh/requirements.txt`，然后启动测试服务并打开 `http://127.0.0.1:8766/optimize`。载入示例可比较四项检查的候选路线，也可以自行输入医嘱。

每次计算冻结一份队列快照。预计等待按时间线性消退，剩余等待乘以 1.15 后向上取整到秒，跨科室移动按 4 分钟。每项检查各自估算排队，第一项从快照时刻出发。首版按未取号建模，暂未模拟已取号、共用排队和时间窗口。建议间隔仍供核对。两种算法使用相同的时间口径，CP-SAT 以最小化末项结束时刻为目标。

打开 `http://127.0.0.1:8766/queues` 查看测试服务的模拟队列。测试队列沿用原模拟器的科室参数和等待公式，各科室独立计时。点击科室名称，再点击「叫下一号」，可立即叫号并重启该科室的倒计时。页面每 2 秒刷新。
